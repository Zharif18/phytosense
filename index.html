🧠 Model Architecture

phytosense_1dcnn — Layer Stack

Input Shape: (500, 1) — single electrode channel
Conv1D × 16 kernel=9, ReLU, same padding + BatchNorm + MaxPool/2
Conv1D × 32 kernel=7, ReLU, same padding + BatchNorm + MaxPool/2
Conv1D × 64 kernel=5, ReLU, same padding + BatchNorm + MaxPool/2
GlobalAvgPool Reduces sequence → fixed vector
Dense 32 ReLU + Dropout(0.3)
Output 5 Softmax — one probability per stress class
